# Kaggle Practice Projects

This repository contains my practice projects based on several Kaggle competitions.  
The goal of this work is to improve my skills in data analysis, machine learning, and model evaluation using real datasets.

I am using these competitions as training exercises to experiment with different techniques, compare models, and strengthen my understanding of the ML workflow (data preprocessing, feature engineering, model training, validation, and interpretation).

# —— Projects included ——

### 1. Titanic – Machine Learning from Disaster
- Binary classification (survival prediction)  
- Algorithms tested: Logistic Regression, Random Forest, SVM  
- Focus on data cleaning, feature engineering, and model comparison

### 2. Pima Indians Diabetes Prediction
- Medical dataset (binary classification)  
- Goal: predict the presence of diabetes based on several health indicators  
- Exploratory data analysis, data scaling, and evaluation metrics

### 3. House Prices – Advanced Regression Techniques
- Regression problem (predicting house prices)  
- Work on feature selection, handling missing data, and model tuning  
- Use of tree-based models and regularized regression techniques

# — Objectives — 
- Practice machine learning methods on real datasets  
- Learn to structure notebooks and code cleanly  
- Experiment with different models and preprocessing techniques  
- Build a small ML portfolio for learning and progression
